# Student Attendance & Marks Tracker

A web application built with **Streamlit** and **Supabase** to manage student records, track daily attendance, and record exam marks. Deployed on **Streamlit Community Cloud**.

## Features

- **Student Management:** Add, view, and update student profiles.
- **Attendance Tracking:** Mark and review daily attendance by date and subject/class.
- **Marks Entry:** Record, edit, and calculate student scores across exams or assignments.
- **Analytics & Reports:** View attendance percentages, grade summaries, and export records.

## Tech Stack

- **Frontend:** Streamlit
- **Database & Auth:** Supabase (PostgreSQL)
- **Hosting:** Streamlit Community Cloud
